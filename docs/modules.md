# 模組設定與使用

這頁說明首頁，Twitch、YouTube、星穹鐵道、存錢記帳四個模組，以及網站通知與外觀的設定與使用方式。帳號與登入見 [部署 › 帳號管理](deploy.md#帳號管理)。

> **圖片與隱私**：頭像、影片縮圖、直播預覽與角色圖都是瀏覽器直接向 YouTube、Twitch、HoYoLAB 的 CDN 載入（不帶 referrer），這些服務會看到你的 IP。網站與資料庫都不存這些圖片與資料，只在快取裡放一段時間。

## 多人使用

每個帳號（站長與邀請的成員）的資料各自分開，看不到也改不到別人的：

| 資料 | 每人一份 | 共用 |
|---|---|---|
| Twitch | 追蹤名單、每位主播的通知開關 | 主播與 Twitch 上的訂閱（同一位主播只訂閱一次） |
| YouTube | 追蹤名單、通知開關、影片清單（自己追蹤頻道的最新 20 支）、翻譯設定與 API Key | 頻道與 WebSub 訂閱、影片的中文字幕狀態、翻譯好的字幕 |
| 星穹鐵道 | 連結的 HoYoLAB 帳號（同一個 UID 只能連結在一個帳號底下） | — |
| 存錢記帳 | 全部 | — |
| 網站通知 | 全部（只收到自己追蹤的、自己帳號的通知） | — |

- 刪除帳號時，自己那一份會一起刪除；共用的翻譯留下但不再連到你（見網站上的使用聲明 `/terms` 第六節）。
- 帳號被停用時等於凍結：排程不處理他的 HoYoLAB 帳號、不寫通知給他，資料與追蹤的訂閱都保留，恢復後照常（見 [部署 › 邀請成員](deploy.md#邀請成員)）。
- 「同步訂閱」（Twitch）與「續訂」（YouTube）處理的是共用的訂閱，誰按都一樣；回應只說自己追蹤的主播或頻道，每個人 60 秒只能按一次。

## 首頁

登入後的首頁是一頁儀表板，一進網站就看得到各模組最重要的資訊。每張卡片右上角的連結（例如「Twitch ›」）到那個模組的頁面；問候語旁那排按鈕是所有模組的入口。

| 卡片 | 內容 | 還沒有資料時 |
|---|---|---|
| 正在直播（Twitch） | 自己追蹤、正在直播的主播：預覽圖、頭像、遊戲名稱、觀看人數、開台多久，點了在新分頁開 Twitch。最多列 4 位，其餘寫「還有 N 位正在直播」 | 沒有追蹤：「去追蹤主播」；沒人在直播：「目前沒有追蹤的主播在直播」 |
| 最新影片（YouTube） | 自己追蹤頻道的最新 4 支：縮圖與狀態標籤（中文字幕、需要翻譯、已翻譯…）、頻道頭像、多久以前。點了照 YouTube 頁的規則：有中文字幕的直接到 YouTube，其他的到翻譯觀看頁 | 「去追蹤頻道」 |
| 即時便箋（星穹鐵道） | 連結的帳號一個一列：開拓力（目前／上限、回滿時間）、後備開拓力、每日實訓、委託（派遣中的角色頭像，完成的打勾）。點帳號名稱到星穹鐵道頁的那個帳號 | 「連結帳號」 |
| 本月存款（存錢記帳） | 這個月已存、應存、還差多少，進度條與達成率 | 「建立項目」 |
| 未讀通知 | 最新 3 則未讀，點了標成已讀並打開連結；更多的寫「還有 N 則未讀」 | 「沒有未讀通知」 |

- **各自載入**：每張卡片各自向資料庫或外部服務讀資料。Twitch、YouTube、HoYoLAB 慢的時候只有那一張顯示載入中；出錯時只有那一張顯示「這張卡片暫時讀不到資料」，可以按「重試」，其他卡片照常。
- **跟模組頁同一份資料**：直播狀態最多是 2 分鐘前、即時便箋最多 5 分鐘前、頭像最多一天前，跟各模組的頁面一樣。
- **還沒設定 Twitch 憑證時**：「正在直播」照開台通知記下的狀態列出，沒有預覽圖與觀看人數，不顯示錯誤。
- **首頁不翻譯、不檢查字幕**：不會在背景重新檢查中文字幕（只在打開 YouTube 頁時做），也不會翻譯。HoYoLAB 回報 cookie 失效時，跟星穹鐵道頁一樣在帳號上標記。
- **未讀通知**跟鈴鐺是同一份資料，在任一邊標成已讀，另一邊也會更新。
- 手機上單欄，卡片照上面表格的順序排。

## Twitch

追蹤主播，開台時在網站上收到通知（用 Twitch 的 EventSub Webhook）。

**設定**

1. 到 [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) 註冊應用程式，取得 Client ID 與 Client Secret，填到 Vercel 的環境變數 `TWITCH_CLIENT_ID`、`TWITCH_CLIENT_SECRET`（見 [密鑰管理](secrets.md)）。OAuth Redirect URL 填 `http://localhost` 即可，用不到。
2. `PUBLIC_BASE_URL` 要設成部署後的網址：Twitch 只會把通知送到公開的 HTTPS 網址。本機測試可以用 ngrok。
3. 開發與正式環境最好各用一個 Twitch 應用程式，因為同一個 Client ID 的訂閱清單是共用的。

**使用**

- **加主播**：在 Twitch 頁輸入主播的帳號、`@帳號` 或頻道網址，按「追蹤」。帳號是 3–25 個英數字或底線。
  - 還沒設定 Twitch 應用程式時，會提示「尚未設定 Twitch 應用程式：請到 Vercel 的環境變數加上 TWITCH_CLIENT_ID 與 TWITCH_CLIENT_SECRET，重新部署後再試」；其他 Twitch 設定（`TWITCH_EVENTSUB_SECRET`、`PUBLIC_BASE_URL`）缺的話也會列出名稱。
- **訂閱狀態**：每位主播都會顯示訂閱狀態，正常情況是從「等待 Twitch 驗證」變成「正常」。
  - Twitch 拒絕建立訂閱時（例如網址不是 HTTPS），會顯示「訂閱失敗：…」，但主播仍會存起來。
  - 失敗原因只顯示中文摘要，例如「連線逾時，稍後會自動重試」「Twitch 拒絕這個請求（400），請確認 PUBLIC_BASE_URL 是公開的 HTTPS 網址」，不顯示 Twitch 回應的原文。
  - 一直停在「等待 Twitch 驗證」，通常是 Twitch 連不到 `PUBLIC_BASE_URL`。
- **同步訂閱**：「同步訂閱」按鈕會對照 Twitch 更新狀態，並補建失敗的訂閱。每天的 `twitch:sync` 排程也會做一樣的事。
  - 處理的是所有人共用的訂閱，但回應只說你自己追蹤的主播，例如「已同步你追蹤的 3 位主播，3 位訂閱正常」。
  - 每個人 60 秒只能按一次，太快再按會提示還要等幾秒。
- **開台通知**：標題是「〈主播〉開台了」，內容是直播標題與分類。Twitch 一時查不到直播資訊時，通知只有「〈主播〉開台了」這一行。
- **關台**：只記錄，不通知。
- **通知開關**：每位主播都有「通知／靜音」開關，只影響自己，不影響追蹤同一位主播的其他人。
- **多人**：追蹤名單每人一份；開台通知只送給追蹤這位主播、而且開著通知的人。刪除主播只是自己不再追蹤，最後一個人也取消時才會刪掉 Twitch 上的訂閱。「最近的開關台紀錄」只列自己追蹤中的主播。

**畫面**

Twitch 頁不論全站是淺色或深色，都是 Twitch 網站的深色風格，版面參考 Twitch 的「追蹤中」頁：

- **直播中**：卡片有直播預覽圖、LIVE、觀看人數、開台多久、頭像、直播標題、遊戲名稱與封面。直播狀態最多是 2 分鐘前的資料。
- **追蹤的頻道**：照 Twitch 側欄的樣子，直播中的排前面（紅點加觀看人數），離線的變灰。點一下展開，可以看訂閱狀態、切換通知、刪除。
- **還沒設定 Twitch 憑證時**：沒有預覽圖與頭像，改用文字頭像與簡單的卡片，直播中照 EventSub 的通知判斷，不顯示錯誤。
- 頭像、離線橫幅與遊戲封面最多是一天前的資料。

## YouTube

### 新影片通知

1. **設定**：WebSub 跟 Twitch 一樣只會送到公開的 HTTPS 網址，所以要先設好 `PUBLIC_BASE_URL` 與 `YOUTUBE_WEBSUB_SECRET`。
2. **加頻道**：在 YouTube 頁上方的輸入框（像 YouTube 的搜尋列）貼上下面任一種，按右邊的按鈕或 Enter。舊式的 `/c/…`、`/user/…` 網址不能用。
   - 頻道網址（`/channel/UC…` 或 `/@帳號`）
   - `@帳號`
   - `UC` 開頭的頻道 ID
3. **通知規則**：只通知發布 24 小時內、第一次看到的影片，而且只送給追蹤這個頻道、開著通知的人。
4. **訂閱續約**：訂閱租約 5 天。`youtube:renew` 每天會續訂快到期（剩不到 2 天）或失敗的頻道，「訂閱內容」旁的「續訂」按鈕可以立刻做一次（回應只說你自己追蹤的頻道；每個人 60 秒只能按一次）。訂閱有問題時頻道頭像的角落會有一個點，點頻道打開選單就看得到「訂閱失敗（…）」的中文摘要（例如「連線逾時，稍後會自動重試」），不顯示 hub 回應的原文。
5. **影片清單**：照 YouTube 的格狀卡片列出自己追蹤頻道的最新 20 支（不在任何人清單裡、發布超過 48 小時的影片，每天的 `youtube:cleanup` 會刪掉；翻譯好的字幕不刪）。追蹤頻道時，會從頻道的 RSS feed 補進最近的影片（不發通知），馬上就看得到；別人已經追蹤的頻道只補發布超過 24 小時的，更新的影片會照常由推送送來並通知所有追蹤者。縮圖用影片 id 組出網址（不呼叫 API），右下角標示「中文字幕」「需要翻譯」「已翻譯」這類狀態；下方是頻道頭像、標題、頻道名稱與「3 小時前」。上方的膠囊可以篩選「有中文字幕」「需要翻譯」「翻譯完成」。翻譯觀看、在 YouTube 開啟、重新檢查中文字幕收在每張卡片的 ⋮ 選單（電腦上滑過卡片才出現，手機上一直都在）。
6. **訂閱內容**：自己追蹤的頻道列在左側（手機是上方可以橫向捲動的頭像列）。點頻道打開選單：訂閱狀態、在 YouTube 開啟頻道、新影片通知開關（只影響自己）、取消追蹤（只是自己不再追蹤，最後一個人也取消時才會取消 WebSub 訂閱）。
7. **頻道頭像**：從頻道頁讀（非官方做法），最多是一天前的資料；讀不到時改用追蹤時存下的頭像或文字頭像。

### 中文字幕判斷

通知前會先判斷影片有沒有中文字幕。只認人工上傳的中文字幕（繁體、簡體都算），自動產生與自動翻譯的不算。

| 中文字幕 | 通知內容 | 影片清單 |
|---|---|---|
| 有 | 「有中文字幕，可以直接看」，連到 YouTube | 縮圖標「中文字幕」，點了直接到 YouTube |
| 沒有 | 「沒有中文字幕，用翻譯觀看」，連到網站的觀看頁 | 縮圖標「需要翻譯」，點了到觀看頁 |
| 無法確認（雲端主機常被 YouTube 擋） | 「無法確認是否有中文字幕」，連到 YouTube | 縮圖標「字幕未確認」，點了到觀看頁 |

很多頻道上片後才補字幕，所以結果會再更新：

- **自動重新檢查**：打開 YouTube 頁時，發布 48 小時內、還不是「有」的影片會在背景重新檢查。每支最多每小時一次，每次最多 5 支，結果要下次打開頁面才看得到。
- **手動重新檢查**：影片 ⋮ 選單裡的「重新檢查中文字幕」。
- 後來才補上的字幕不會再發一次通知。

### 翻譯設定（AI 供應商）

在 YouTube 頁按「翻譯設定」，選要用的 AI 並填入 API Key。設定與 API Key 每個人各自一份，Key 會加密後才存進資料庫，畫面上只顯示末 4 碼；刪除帳號時一起刪除。

| AI | 預設模型 | 費用 |
|---|---|---|
| Claude（Anthropic） | `claude-haiku-4-5` | 要另外申請 API Key，依用量計費 |
| OpenAI | `gpt-4.1-mini` | 要另外申請 API Key，依用量計費 |
| Gemini（Google） | `gemini-3.8-flash`（想省錢可改 `gemini-3.5-flash-lite`） | 可以用 [Google AI Studio](https://aistudio.google.com) 的免費 API Key。有每日用量上限，免費方案的內容可能被 Google 用來改善產品 |

- ChatGPT Plus、Claude Pro、Gemini（包括 Google AI Pro）這類訂閱方案都**不能直接當 API Key 用**：訂閱的用量只在各家的 App 與網頁裡，用 API Key 呼叫是另外計費（[Google 的說明](https://ai.google.dev/gemini-api/docs/google-ai-plans)）。
- **Google AI Pro 附的 Cloud 抵免額**：Google AI Pro 訂閱每月附 Google Cloud 抵免額（2026 年 10 月查到的是每月 US$10，透過 Google Developer Program 發放），可以拿來付 Gemini API 的費用。
  - 領法：到 [Google Developer Program](https://developers.google.com/program) 啟用，在「My Benefits」把抵免額套用到 Google Cloud 的帳單帳戶；只限個人 Google 帳號，抵免額發放後一年到期（[官方說明](https://developers.google.com/profile/help/benefits)）。
  - AI Studio 新開的帳單帳戶預設是預付制：要先買預付額度（最少 US$5），Cloud 抵免額才能用在 Gemini API；預付額度用完時 API 會停用（[官方說明](https://ai.google.dev/gemini-api/docs/billing)）。
  - 金額與條件以 Google 當時的方案為準。
- **Gemini 的預設模型**：`gemini-3.8-flash` 是 Google 建議新專案使用的正式版 Flash；想省錢、量大時可以改填 `gemini-3.5-flash-lite`。Google 從 2026 年 9 月起只讓過去用過 2.5 系列的人繼續用 `gemini-2.5-flash`。型號清單見 [Gemini 模型](https://ai.google.dev/gemini-api/docs/models)。
- 模型欄位留空就用預設值。
- 「專有名詞表」每行寫一個 `韓文=中文`，例如成員名、團名、節目名。
  - 最多 200 筆、每個詞 50 字以內，所有詞條合計 5,000 字以內；超過時不會儲存，畫面會說明超過哪一項。
  - 翻譯時只把這一批字幕與前後幾句裡實際出現的詞送給 AI，表再長也不會每批都多付費用。

### 觀看頁與即時翻譯

**翻譯共用**

- 同一支影片的翻譯所有人共用：別人已經翻好（或翻到一半）的影片，打開就看得到，不用再花一次費用。
- 接著翻（續翻）用的是觀看者自己的 API Key；還沒設定 API Key 的人只能看已經翻好的部分，畫面會提示到「翻譯設定」填入。
- **別人發起、還沒翻完的翻譯不會自動用你的 API Key 接著翻**（「自動即時翻譯」開著也一樣）：先顯示已經翻好的部分，按「用我的 API Key 繼續翻譯」才開始。自己發起的翻譯照常自動接著翻；翻完的翻譯所有人都能直接看。
- **你的 API Key 出問題時只影響你**：金鑰無效、額度用完、請求太頻繁或連線中斷時，錯誤只顯示給你，翻譯維持排隊中，其他人看不到你的錯誤、照樣可以接著翻。只有跟字幕內容有關的問題（AI 輸出格式不對、模型拒絕翻譯）才會把翻譯標成失敗。
- 網站記下每份翻譯的發起人（開始翻譯、上傳字幕或重新翻譯的人）與他當時的專有名詞表，之後誰接著翻都用同一份專有名詞表，譯名才會一致。
- 只有發起人或站長可以「重新翻譯」或「上傳字幕」取代；其他人看不到這兩個按鈕。做的人會成為新的發起人。
- 發起人刪除帳號後，翻譯留給其他人，之後只有站長能重新翻譯。

**什麼時候會呼叫 AI**

- 只在觀看頁上翻譯。
- 開始翻譯的方式有三種：按下播放（「自動即時翻譯」開著時）、按「開始翻譯」、上傳字幕檔。
- 開始之後，只要觀看頁開著，就會一直翻到完成，影片暫停時也會繼續。別人發起的翻譯要先按「用我的 API Key 繼續翻譯」（見上面〈翻譯共用〉）。
- 離開頁面就停，回來後接著翻。
- 新影片通知、排程與背景檢查都不會翻譯。

**翻譯的順序**

- **先翻快要播到的**：15 秒內就會播到的句子用 10 句的小批次，所以字幕幾秒內就會出現。
- **其餘的**：每批 30 句，翻到目前位置前方約 2 分半，再從頭補完整支影片。
- **拖曳進度**：拖到別的時間後，下一批就從新的位置開始翻。

**畫面與操作**

- **版面**：照 YouTube 的觀看頁。播放器下方是標題與頻道列，翻譯的按鈕（開始翻譯、自動即時翻譯、用我的 API Key 繼續翻譯、字幕語言與大小、全螢幕、下載、上傳字幕、重新翻譯）是頻道列右邊的膠囊（手機上可以橫向捲動），翻譯進度在下面的灰色區塊；電腦上右側是「接下來播放」，手機排在下方。
- **自動即時翻譯**：預設開啟，開關記在各瀏覽器裡，同一個瀏覽器的其他分頁會跟著同步。關掉之後，改成手動按「開始翻譯」。
- **還沒設定 API Key**：會提示先到「翻譯設定」填入。
- **還沒翻好的句子**：先顯示韓文。翻譯進行中標「翻譯中」，暫停或失敗時標「尚未翻譯」。
- **費用**：翻好的字幕會保存，重看不會再收費。
- **重新翻譯**：「重新翻譯」會清空譯文、從頭再翻，會再花一次費用。
- **出錯時**：
  - AI 輸出格式不對、模型拒絕翻譯：翻譯標成失敗，有 API Key 的人都可以按「重試」接著翻。
  - 你的 API Key 無效、額度用完、請求太頻繁或連線中斷：只有你看得到錯誤（金鑰的問題會附上「翻譯設定」連結），翻譯維持排隊中；處理好之後按「繼續翻譯」。
- **字幕顯示**：可以切換中文／雙語／韓文（預設雙語），也可以調整字幕大小；大小記在瀏覽器裡，其他分頁會同步。
- **下載字幕**：可以下載中文、雙語、韓文的 `.srt`，以及中文的 `.vtt`，還沒翻好的句子用韓文補上。翻譯是共用的，登入的人都可以下載任何已經有翻譯的影片字幕（跟觀看頁看到的一樣）。
- **翻譯沒追蹤的影片**：在 YouTube 頁上方的輸入框貼上影片網址或 11 碼影片 ID。網址可以是 watch、youtu.be、shorts、embed 或 live。
- **翻譯永久保留**：影片從清單裡清掉、頻道沒有人追蹤時，翻譯好的字幕都不會刪除。

### 抓不到字幕時

YouTube 官方 API 只能下載自己頻道的字幕，所以這裡改讀影片頁面裡的字幕資訊（非官方做法）。優先用人工上傳的韓文字幕，沒有的話才用自動產生的，畫面上會標示準確度較低。

YouTube 常擋雲端主機的 IP。抓不到字幕時，改在自己電腦下載再上傳：

```bash
yt-dlp --write-subs --write-auto-subs --sub-langs ko --skip-download "影片網址"
```

- **上傳**：在觀看頁按「上傳字幕」，選產生的 `.ko.vtt`（或 `.srt`）。
  - 檔案上限 900 KB，最多 5,000 句（超過的多半是傳錯檔案，會被拒絕）。
  - 編碼可以是 UTF-8 或韓文 Windows 的 CP949。
  - 自動字幕的滾動格式會自動整理。
- **換掉已翻好的字幕**：已經翻好的影片也能按「上傳字幕」。這會取代原本的字幕並從頭翻，會再花一次費用。

### 全螢幕

- 請用標題下方那排按鈕裡的「全螢幕」，字幕會跟著一起放大。
- iPhone Safari 不支援這種全螢幕，所以不會出現這個按鈕。只能用 YouTube 自己的全螢幕，但這樣**看不到疊加的字幕**。
- 需要的話，下載字幕檔，搭配支援外掛字幕的播放器。

## 星穹鐵道

連結自己的 HoYoLAB 帳號，提供即時便箋、角色與遺器、開拓月曆、終局戰績、兌換碼、每日自動簽到與開拓力快滿提醒。

> ⚠️ **免責說明**：HoYoLAB 沒有公開 API，這裡用的是非官方介面（參考 genshin.py），尚未用真實帳號完整驗證，HoYoLAB 改版就可能失效。請只用在自己的帳號，使用風險自負。

**連結帳號**

1. 用電腦瀏覽器登入 [hoyolab.com](https://www.hoyolab.com)，打開開發者工具 → Application → Cookies，複製 `ltoken_v2`、`ltuid_v2`。有 `ltmid_v2` 也一起複製，少了它即時便箋可能失敗。
2. 貼到星穹鐵道頁的「連結帳號」。
   - cookie 會加密後才存進資料庫，畫面上不會再顯示。
   - 只有一個伺服器有角色時直接連結。好幾個伺服器都有角色時，會列出每個伺服器（台港澳服、亞服、美服、歐服）的暱稱、等級與 UID，勾選要連結的帳號；預設勾等級最高的，等級很低的會標「可能是沒在玩的帳號」。兩個步驟之間 cookie 只留在瀏覽器的表單裡。
3. 要用兌換碼的話，cookie 要一併貼上 `cookie_token_v2`、`account_id_v2`（或 `account_mid_v2`）。

**多人**

- 連結的帳號每人一份，別人看不到你的帳號、便箋與戰績。
- 同一個遊戲帳號（UID）只能連結在一個帳號底下：別人已經連結的 UID 會被拒絕，並說明「已經被其他使用者連結」。
- 每日簽到與開拓力提醒照常處理所有人的帳號，通知只送給帳號的擁有者；擁有者被停用時，排程不會用他的 cookie 簽到或查便箋，恢復後照常。

**功能**

頁面不論全站是淺色或深色，都是遊戲裡的深藍星空風格（背景是自己畫的，不用官方美術圖）。連結了兩個以上的帳號時，上方可以用伺服器切換帳號（網址會帶 `?account=<id>`，重新整理也會保留），下面每一塊都只顯示選到的帳號。

- **即時便箋**：開拓力、後備開拓力、每日實訓等，最多是 5 分鐘前的資料。派遣中的委託會顯示角色頭像與剩餘時間。
- **角色**：所有角色的頭像、名字、等級、星魂、屬性、命途與稀有度，可以依稀有度或屬性篩選、排序。點角色打開詳情：立繪、光錐（等級、疊影）、四件遺器與兩件位面飾品（主屬性、副屬性與強化次數）、面板（基礎、加成、最終）、星魂與行跡。最多是 30 分鐘前的資料。
- **開拓月曆**：這個月與上個月拿到的星瓊與車票、跟上個月比增減幾 %，以及星瓊的來源比例；可以切換 HoYoLAB 給得到的幾個月份。
- **終局戰績**：混沌回憶、虛構敘事、末日幻影的本期與上期：期數名稱與時間、總星數、最高關卡、每一關的星數與回合數（或分數），以及上場隊伍。
- **兌換碼**：跟官方兌換頁一樣，輸入兌換碼按「兌換」，獎勵會寄到遊戲內信箱。兌換碼與結果都不存；兩次兌換之間要等約 5 秒。
- **每日簽到**：
  - 每天 00:10（台北時間）自動簽到。Vercel Hobby 只保證在 00 點那個小時內執行。
  - 同一個 HoYoLAB 帳號只簽到一次。全部帳號都是「今天已經簽到過了」時不通知；其他情況會通知成功或失敗。
  - 也可以按「立即簽到」，這樣不會發通知。
- **開拓力提醒**：
  - 開拓力達到門檻時通知一次，要降到門檻以下才會再提醒。
  - 門檻預設是「上限 − 20」。每個角色都可以用「設定提醒門檻」改成 0–1000，留空就改回預設。
  - 門檻設得比上限高，就等於關閉提醒。

**常見狀況**

- **cookie 失效**：登出 HoYoLAB 或改密碼後，cookie 會失效，卡片上會標示出來。重新貼一次新的 cookie 即可。
- **角色或戰績顯示「沒有公開」**：到 HoYoLAB → 戰績 → 設定，打開角色詳情與戰績的公開設定，幾分鐘後重新整理。
- **兌換碼說缺少 cookie 欄位**：用頁面下方的「新增帳號或更新 cookie」重新連結，cookie 一併貼上 `cookie_token_v2`、`account_id_v2`。
- **要求驗證碼**：簽到偶爾會被要求驗證碼，這時要到 HoYoLAB 網站手動簽到一次。

## 存錢記帳

不需要外部服務，打開 `/savings` 就能用。頁面重點先顯示，次要的資訊收在下面可以展開的區塊。

1. **本月總覽**（最上面）：已存、應存、還差多少、進度條與達成率，以及幾個項目已經存滿。
   - 右上角切換月份（上一月、下一月或選單），可以補記過去的月份，但不能記未來的月份；不在本月時有「回到本月」。
   - 已存包含臨時存款；還差是每個啟用中的項目還沒存滿的部分，臨時存款不抵項目。
2. **本月項目**：每個啟用中的固定項目一列，只有名稱、狀態（已存滿、還差多少、還沒存）與每月金額。
   - 按「記一筆」才出現輸入框，金額預設是還差的部分；已經存滿的項目沒有這個按鈕。
   - 不屬於任何項目的錢，按「臨時存款」輸入金額與備註。
3. **收起來的區塊**（點標題展開）：
   - **紀錄明細**：選到的月份的每一筆存款、備註與記錄時間。紀錄可以刪除，不能修改。
   - **統計**：今年累計、全部累計、最近 12 個月的長條圖（點長條切換到那個月，也可以改用表格檢視）與各項目的累計。今年與全部累計一律以目前的月份計算，不受切換的月份影響。
   - **管理項目**：新增、修改（名稱、每月金額、備註）、上下調整順序、停用、刪除固定項目。停用的項目不列入應存與本月項目。

- 金額是新台幣整數，範圍 1 元到 1 億元。「本月」以台北時間計算。
- **記帳資料永久保留**，沒有清理排程。刪除項目時，過去的紀錄會留著，標示「已刪除」。
- 項目與紀錄每人一份；刪除帳號時一起刪除。

## 網站通知

通知只出現在網站裡，不會送到外部服務。每個人只收到、只看得到自己的通知（自己追蹤的主播與頻道、自己連結的星鐵帳號），標為已讀也只影響自己。被停用的帳號不會收到新的通知。

- **鈴鐺**：在導覽列右上角，顯示未讀數，點開是最近 10 則。
  - 各模組的導覽按鈕也會標示自己的未讀數。
  - 分頁開著時每 10 秒檢查一次新通知，分頁在背景時改成每 60 秒；切回分頁時立刻檢查。
- **提示卡片與提示音**：有新通知時，右下角會跳出卡片（最多 3 張，6 秒後消失），並播一聲提示音。
  - 瀏覽器規定要先在頁面上點過任何地方，才能播放聲音。
  - 開好幾個分頁時，提示音只會響一次。
- **提醒方式依模組分開設定**：每個會發通知的模組各有「提示音」「瀏覽器通知」兩個開關，例如 Twitch 全開、YouTube 都關。存錢記帳不會發通知，所以不在清單裡。
  - **在哪裡設定**：鈴鐺面板右上角的齒輪（提醒方式），或通知頁的「提醒方式」。兩邊是同一份設定，改了會立刻同步。
  - **兩個都關的模組**：只算進未讀數字，不跳提示卡片、不響、不跳系統通知。
  - **未讀數字**：一律顯示所有模組的未讀數，不受這些開關影響。
  - **存在瀏覽器**：每台裝置可以不同（例如手機只亮數字），同一個瀏覽器的其他分頁會跟著同步。預設全開；更新前在舊版關掉提示音或瀏覽器通知的話，還沒個別設定的模組沿用原本的設定。
  - **新增模組**：開關會自動出現，不用另外設定。
- **瀏覽器通知**（選用）：開著瀏覽器通知的模組，在網站位於背景分頁時會跳出系統通知。
  - 打開任何一個模組的瀏覽器通知時，如果還沒允許，瀏覽器會詢問要不要允許；也可以按「允許」或通知頁的「允許瀏覽器通知」。
  - 被拒絕（封鎖）時，鈴鐺面板與通知頁會提示：要到瀏覽器的網站設定，把這個網站的通知改成允許。
  - Android 的 Chrome 不能直接跳出系統通知。
  - iPhone 要先把網站加到主畫面。
- **通知開關**：Twitch 主播展開後、YouTube 頻道的選單裡都有開關，只影響自己。關掉時照樣記錄，只是不寄給你。
- **通知頁**（`/notifications`）：可以依模組篩選、標為已讀，也可以試聽提示音、傳送測試通知。通知**保留 14 天**。
