# 模組設定與使用

這頁說明 Twitch、YouTube、星穹鐵道、存錢記帳四個模組，以及網站通知的設定與使用方式。帳號與登入見 [部署 › 帳號管理](deploy.md#帳號管理)。

## Twitch

追蹤主播，開台時在網站上收到通知（用 Twitch 的 EventSub Webhook）。

**設定**

1. 到 [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) 註冊應用程式，取得 Client ID 與 Client Secret，填到 Vercel 的環境變數 `TWITCH_CLIENT_ID`、`TWITCH_CLIENT_SECRET`（見 [密鑰管理](secrets.md)）。OAuth Redirect URL 填 `http://localhost` 即可，用不到。
2. `PUBLIC_BASE_URL` 要設成部署後的網址：Twitch 只會把通知送到公開的 HTTPS 網址。本機測試可以用 ngrok。
3. 開發與正式環境最好各用一個 Twitch 應用程式，因為同一個 Client ID 的訂閱清單是共用的。

**使用**

- **加主播**：在 Twitch 頁輸入主播的帳號、`@帳號` 或頻道網址，按「追蹤」。帳號是 3–25 個英數字或底線。
- **訂閱狀態**：每位主播都會顯示訂閱狀態，正常情況是從「等待 Twitch 驗證」變成「正常」。
  - Twitch 拒絕建立訂閱時（例如網址不是 HTTPS），會顯示「訂閱失敗：…」，但主播仍會存起來。
  - 失敗原因只顯示中文摘要，例如「連線逾時，稍後會自動重試」「Twitch 拒絕這個請求（400），請確認 PUBLIC_BASE_URL 是公開的 HTTPS 網址」，不顯示 Twitch 回應的原文。
  - 一直停在「等待 Twitch 驗證」，通常是 Twitch 連不到 `PUBLIC_BASE_URL`。
- **同步訂閱**：「同步訂閱」按鈕會對照 Twitch 更新狀態，並補建失敗的訂閱。每天的 `twitch:sync` 排程也會做一樣的事。
- **開台通知**：標題是「〈主播〉開台了」，內容是直播標題與分類。Twitch 一時查不到直播資訊時，通知只有「〈主播〉開台了」這一行。
- **關台**：只記錄，不通知。
- **通知開關**：每位主播都有「通知／靜音」開關。

## YouTube

### 新影片通知

1. **設定**：WebSub 跟 Twitch 一樣只會送到公開的 HTTPS 網址，所以要先設好 `PUBLIC_BASE_URL` 與 `YOUTUBE_WEBSUB_SECRET`。
2. **加頻道**：在 YouTube 頁輸入下面任一種，按「追蹤」。舊式的 `/c/…`、`/user/…` 網址不能用。
   - 頻道網址（`/channel/UC…` 或 `/@帳號`）
   - `@帳號`
   - `UC` 開頭的頻道 ID
3. **通知規則**：只通知發布 24 小時內、第一次看到的影片。
4. **訂閱續約**：訂閱租約 5 天。`youtube:renew` 每天會續訂快到期（剩不到 2 天）或失敗的頻道，「續訂」按鈕可以立刻做一次。訂閱失敗時頻道列會顯示「訂閱失敗：…」的中文摘要（例如「連線逾時，稍後會自動重試」），不顯示 hub 回應的原文。
5. **影片清單與開關**：影片清單列出最近 30 支；每個頻道都有「通知／靜音」開關。

### 中文字幕判斷

通知前會先判斷影片有沒有中文字幕。只認人工上傳的中文字幕（繁體、簡體都算），自動產生與自動翻譯的不算。

| 中文字幕 | 通知內容 | 影片清單 |
|---|---|---|
| 有 | 「有中文字幕，可以直接看」，連到 YouTube | 「有中文字幕」＋「在 YouTube 看」 |
| 沒有 | 「沒有中文字幕，用翻譯觀看」，連到網站的觀看頁 | 「沒有中文字幕」＋「翻譯觀看」 |
| 無法確認（雲端主機常被 YouTube 擋） | 「無法確認是否有中文字幕」，連到 YouTube | 「字幕未確認」＋「翻譯觀看」 |

很多頻道上片後才補字幕，所以結果會再更新：

- **自動重新檢查**：打開 YouTube 頁時，發布 48 小時內、還不是「有」的影片會在背景重新檢查。每支最多每小時一次，每次最多 5 支，結果要下次打開頁面才看得到。
- **手動重新檢查**：按該列的「重新檢查」。
- 後來才補上的字幕不會再發一次通知。

### 翻譯設定（AI 供應商）

在 YouTube 頁按「翻譯設定」，選要用的 AI 並填入 API Key。Key 會加密後才存進資料庫，畫面上只顯示末 4 碼。

| AI | 預設模型 | 費用 |
|---|---|---|
| Claude（Anthropic） | `claude-haiku-4-5` | 要另外申請 API Key，依用量計費 |
| OpenAI | `gpt-4.1-mini` | 要另外申請 API Key，依用量計費 |
| Gemini（Google） | `gemini-2.5-flash` | 可以用 [Google AI Studio](https://aistudio.google.com) 的免費 API Key。有每日用量上限，免費方案的內容可能被 Google 用來改善產品 |

- ChatGPT Plus、Claude Pro、Gemini 這類訂閱方案都**不包含 API**。
- 模型欄位留空就用預設值。
- 「專有名詞表」每行寫一個 `韓文=中文`，例如成員名、團名、節目名。

### 觀看頁與即時翻譯

**什麼時候會呼叫 AI**

- 只在觀看頁上翻譯。
- 開始翻譯的方式有三種：按下播放（「自動即時翻譯」開著時）、按「開始翻譯」、上傳字幕檔。
- 開始之後，只要觀看頁開著，就會一直翻到完成，影片暫停時也會繼續。
- 離開頁面就停，回來後接著翻。
- 新影片通知、排程與背景檢查都不會翻譯。

**翻譯的順序**

- **先翻快要播到的**：15 秒內就會播到的句子用 10 句的小批次，所以字幕幾秒內就會出現。
- **其餘的**：每批 30 句，翻到目前位置前方約 2 分半，再從頭補完整支影片。
- **拖曳進度**：拖到別的時間後，下一批就從新的位置開始翻。

**畫面與操作**

- **自動即時翻譯**：預設開啟，開關記在各瀏覽器裡，同一個瀏覽器的其他分頁會跟著同步。關掉之後，改成手動按「開始翻譯」。
- **還沒設定 API Key**：會提示先到「翻譯設定」填入。
- **還沒翻好的句子**：先顯示韓文。翻譯進行中標「翻譯中」，暫停或失敗時標「尚未翻譯」。
- **費用**：翻好的字幕會保存，重看不會再收費。
- **重新翻譯**：「重新翻譯」會清空譯文、從頭再翻，會再花一次費用。
- **出錯時**：翻譯失敗時可以按「重試」；連線中斷時可以按「繼續翻譯」。
- **字幕顯示**：可以切換中文／雙語／韓文（預設雙語），也可以調整字幕大小；大小記在瀏覽器裡，其他分頁會同步。
- **下載字幕**：可以下載中文、雙語、韓文的 `.srt`，以及中文的 `.vtt`。還沒翻好的句子用韓文補上。
- **翻譯沒追蹤的影片**：在 YouTube 頁的「貼任何 YouTube 影片網址來翻譯字幕」貼上網址或 11 碼影片 ID，按「開啟」。網址可以是 watch、youtu.be、shorts、embed 或 live。

### 抓不到字幕時

YouTube 官方 API 只能下載自己頻道的字幕，所以這裡改讀影片頁面裡的字幕資訊（非官方做法）。優先用人工上傳的韓文字幕，沒有的話才用自動產生的，畫面上會標示準確度較低。

YouTube 常擋雲端主機的 IP。抓不到字幕時，改在自己電腦下載再上傳：

```bash
yt-dlp --write-subs --write-auto-subs --sub-langs ko --skip-download "影片網址"
```

- **上傳**：在觀看頁上傳產生的 `.ko.vtt`（或 `.srt`）。
  - 檔案上限 900 KB。
  - 編碼可以是 UTF-8 或韓文 Windows 的 CP949。
  - 自動字幕的滾動格式會自動整理。
- **換掉已翻好的字幕**：已經翻好的影片也能選「改用自己的字幕檔」。這會取代原本的字幕並從頭翻，會再花一次費用。

### 全螢幕

- 請用播放器下方的「全螢幕」按鈕，字幕會跟著一起放大。
- iPhone Safari 不支援這種全螢幕，所以不會出現這個按鈕。只能用 YouTube 自己的全螢幕，但這樣**看不到疊加的字幕**。
- 需要的話，下載字幕檔，搭配支援外掛字幕的播放器。

## 星穹鐵道

連結自己的 HoYoLAB 帳號，提供即時便箋、每日自動簽到與開拓力快滿提醒。

> ⚠️ **免責說明**：HoYoLAB 沒有公開 API，這裡用的是非官方介面（參考 genshin.py），尚未用真實帳號完整驗證，HoYoLAB 改版就可能失效。請只用在自己的帳號，使用風險自負。

**連結帳號**

1. 用電腦瀏覽器登入 [hoyolab.com](https://www.hoyolab.com)，打開開發者工具 → Application → Cookies，複製 `ltoken_v2`、`ltuid_v2`。有 `ltmid_v2` 也一起複製，少了它即時便箋可能失敗。
2. 貼到星穹鐵道頁的「連結帳號」。
   - cookie 會加密後才存進資料庫，畫面上不會再顯示。
   - 這個 HoYoLAB 帳號底下的每個星穹鐵道角色，各會有一張卡片。

**功能**

- **即時便箋**：開拓力、後備開拓力、每日實訓等，最多是 5 分鐘前的資料。
- **每日簽到**：
  - 每天 00:10（台北時間）自動簽到。Vercel Hobby 只保證在 00 點那個小時內執行。
  - 同一個 HoYoLAB 帳號只簽到一次。全部帳號都是「今天已經簽到過了」時不通知；其他情況會通知成功或失敗。
  - 也可以按「立即簽到」，這樣不會發通知。
- **開拓力提醒**：
  - 開拓力達到門檻時通知一次，要降到門檻以下才會再提醒。
  - 門檻預設是「上限 − 20」。每個角色都可以用「設定提醒門檻」改成 0–1000，留空就改回預設。
  - 門檻設得比上限高，就等於關閉提醒。

**常見狀況**

- **cookie 失效**：登出 HoYoLAB 或改密碼後，cookie 會失效，卡片上會標示出來。重新貼一次新的 cookie 即可。
- **要求驗證碼**：簽到偶爾會被要求驗證碼，這時要到 HoYoLAB 網站手動簽到一次。

## 存錢記帳

不需要外部服務，打開 `/savings` 就能用。

1. **每月固定項目**：新增要固定存的項目，例如緊急預備金每月 10,000 元。
   - 項目可以修改、停用，也可以用上下箭頭調整順序。
   - 停用的項目不列入本月預計與本月紀錄。
2. **本月紀錄**：列出每個啟用中的項目這個月存了沒。
   - 按「記錄本月已存」記一筆，金額預設是還差的部分。
   - 不屬於任何項目的錢，用「新增臨時存款」記。
   - 可以切換月份補記，但不能記未來的月份。
   - 紀錄可以刪除，不能修改。
3. **歷史**：
   - 最近 12 個月的長條圖。點長條會跳到那個月，也可以改用表格檢視。
   - 各項目的累計金額。

- 上方的本月預計、本月已存、今年累計、全部累計，一律以目前的月份計算，不受上面切換的月份影響。
- 金額是新台幣整數，範圍 1 元到 1 億元。「本月」以台北時間計算。
- **記帳資料永久保留**，沒有清理排程。刪除項目時，過去的紀錄會留著，標示「已刪除」。

## 網站通知

通知只出現在網站裡，不會送到外部服務。

- **鈴鐺**：在導覽列右上角，顯示未讀數，點開是最近 10 則。
  - 各模組的導覽按鈕也會標示自己的未讀數。
  - 分頁開著時每 10 秒檢查一次新通知，分頁在背景時改成每 60 秒；切回分頁時立刻檢查。
- **提示卡片與提示音**：有新通知時，右下角會跳出卡片（最多 3 張，6 秒後消失），並播一聲提示音。
  - 瀏覽器規定要先在頁面上點過任何地方，才能播放聲音。
  - 開好幾個分頁時，提示音只會響一次。
- **提醒方式依模組分開設定**：每個會發通知的模組各有「提示音」「瀏覽器通知」兩個開關，例如 Twitch 全開、YouTube 都關。存錢記帳不會發通知，所以不在清單裡。
  - **在哪裡設定**：鈴鐺面板右上角的齒輪（提醒方式），或通知頁的「提醒方式」。兩邊是同一份設定，改了會立刻同步。
  - **兩個都關的模組**：只算進未讀數字，不跳提示卡片、不響、不跳系統通知。
  - **未讀數字**：一律顯示所有模組的未讀數，不受這些開關影響。
  - **存在瀏覽器**：每台裝置可以不同（例如手機只亮數字），同一個瀏覽器的其他分頁會跟著同步。預設全開；更新前在舊版關掉提示音或瀏覽器通知的話，還沒個別設定的模組沿用原本的設定。
  - **新增模組**：開關會自動出現，不用另外設定。
- **瀏覽器通知**（選用）：開著瀏覽器通知的模組，在網站位於背景分頁時會跳出系統通知。
  - 打開任何一個模組的瀏覽器通知時，如果還沒允許，瀏覽器會詢問要不要允許；也可以按「允許」或通知頁的「允許瀏覽器通知」。
  - 被拒絕（封鎖）時，鈴鐺面板與通知頁會提示：要到瀏覽器的網站設定，把這個網站的通知改成允許。
  - Android 的 Chrome 不能直接跳出系統通知。
  - iPhone 要先把網站加到主畫面。
- **通知開關**：Twitch 主播與 YouTube 頻道的每一列都有開關。關掉時照樣記錄，只是不建立通知。
- **通知頁**（`/notifications`）：可以依模組篩選、標為已讀，也可以試聽提示音、傳送測試通知。通知**保留 14 天**。
